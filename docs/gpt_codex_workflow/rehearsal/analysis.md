原题：历史实体A在绝对时刻0,2,4,6,8 min的液位分别12,11.8,11.6,11.4,11.2 L，其历史阈值10 L终点20 min在20 min可用。当前实体B从绝对100 min起，时刻100,102,...,112液位为11.8,11.6,...,10.6 L；各记录当时可用，未来终点不提供。要求：REQ-A根据REQ-B的条件剩余时间，以1 L/min需求采购3L/4元和5L/7元整箱冷却液，使成本最小；REQ-B估计当前剩余时间并用A的4和8 min历史起点评价误差；REQ-C给完整库存序列和守恒，依赖A、B。价格/液位全为合成输入，不是经验数据。
