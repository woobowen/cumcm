# 逐问阅读附页与论文事实接口

阅读附页必须标 **DERIVED_READING_VIEW**：从已冻结证据派生，不能改变case state、原statement、Run、Final或工程资格。旧产物不原地改；新case在M04/M09就给完整符号和具体statement，M14仍核完整血缘。

## 一份新附页的填写模板

```
视图版本：[版本]；生成日期：[实际日期]；DERIVED_READING_VIEW
case/revision：[实际值]；原M14 package_hash：[原值]
源文件相对路径/sha256：[逐件列出]；脱敏视图sha256：[若不同则分别列]
源字节可得性：[实际已核/只有hash引用]
当前性：[本机验证结果或历史快照；不是只看包完整]
```

每个符号一行：符号｜中文含义｜单位｜索引/时间坐标｜适用条件｜原公式/字段。预测起点t0、阈值终点T、绝对观测时间t和库存相对时间τ不得混写；流率q的L/min与库存s的L分开。每个公式出现的变量都要覆盖，不能只给“min”这种单位。

每问一行：原要求/REQ ID｜明确中文结论｜值/方案及单位｜条件/样本范围｜claim_id｜selected Run ID｜metric/输出字段｜source/output sha256｜独立核验/Final引用｜没有证明什么。

中文句式：在[实际假设和数据范围]下，[对象]得到[数值/方案和单位]；依据[Run、指标、字段]及[实际核查]；尚未证明[具体外推]。不要保留“Bounded result”作为唯一结论，不预填成功或赛题答案。未完成的问写证据不足及已有结果，不能借附页变成整体READY。

## 五种事实接口

| 接口 | 读取内容 | 可以调整 | 不能改动与回传规则 |
|---|---|---|---|
| 论文文字 | 逐问事实、方程、条件、来源、反例、限制 | 组织语言、解释逻辑、引用呈现 | 不将模拟写实测、条件预测写已验证精度；疑点回传字段/Claim |
| 数据图 | 同一有效Run的figure-ready data、单位、样本、区间机制 | 色彩/坐标样式；转换须保留公式与原表 | 不修改数据点/隐去失败；轴单位和误差含义保留 |
| 模型示意图 | 已确认对象、机制、依赖与公式 | 节点位置、线条、注释 | 图不能新增因果箭头或当成数值证据 |
| 表格 | 原输出字段、指标口径、数值、单位、有效样本量 | 小数位/表头/排列；保留未舍入源值 | 不混合revision或选择性删除负结果；舍入误差单列 |
| 排版/提交接口 | 版本清单、引用、图表编号、文件需求 | 版式、交叉引用、格式 | 不替换实验事实或代记人工核验；本资料不制作成品/提交 |

交接前核摘要数字、正文、表格、数据图是否引用同一Run和revision；总量/比例/单位/舍入一致。示意图单列为机制表达。引用真实来源；自动生成的公式或表格仍须核对。事实更正交回Codex指定模块，不能因文案改动重启旧Final。此处只约定接口，不修改其他写作或绘图Skill。
