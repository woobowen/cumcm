# Upstream evaluation policy

All candidates begin `EVALUATE`. Static review distinguishes `CLAIMED`, `OBSERVED`, `UNKNOWN`, and `UNVERIFIED`; it records exact commit/evidence and uses provisional weighted dimensions from `static_evaluation.csv`. Stars, author claims, and totals cannot select a base.

Foundation permits identity lookup, isolated shallow cloning, and text/tree/license/security inspection only. Candidate scripts, hooks, binaries, Makefiles, package installs, MCP servers, and external services are never executed. Reuse status changes require dynamic phase evidence, license/security clearance, compatibility tests, an ADR, and human approval.
