# Search and answer-leakage policy

## `PREPARATION_MODE`

Public Skills, generic methods, historical material, original papers, standards, official data, and software docs may be searched with source records. Adoption still requires evidence/license/security review.

## `BLIND_BENCHMARK_MODE`

Do not search year plus problem number, full title, distinctive source sentence, attachment filename, unique entity combined with answer/solution/excellent-paper/code, solution blogs, answer repositories, videos, or discussion platforms. Generic methods, primary research, official software docs/data, textbooks, and standards remain allowed. Freeze the Skill and log searches/interventions.

## `LIVE_CONTEST_MODE`

Do not search/browse discussion of the current contest problems. Permit only general theory, original research, official data, and software documentation; log every query and AI use, prefer local capability, and stop/register risk when compliance is uncertain.

Viewing an answer permanently demotes a validation/held-out case to development. Leakage scanning uses generic indicators and context allowlists, never hardcoded historical titles/answers.
