# Modeling-to-paper interface

The sole machine contract is `contracts/modeling_to_paper.schema.json`. A handoff contains requirements/traceability, data dictionary/quality, assumptions/symbols/formulas/sources, selected models and exact final runs/metrics, result tables and figure-ready data, validation/robustness/uncertainty/failures/limitations, claim-evidence links, reproduction instructions, generation time, and approval.

The paper team may transform presentation but must preserve identifiers, values, uncertainty, limitations, and provenance. Requested factual changes return to the modeling workflow and produce a new decision/run/package version; prose cannot overwrite experimental truth.
