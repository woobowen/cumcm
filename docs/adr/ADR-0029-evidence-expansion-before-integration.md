# ADR-0029: Complete audited evidence expansion before integration

Status: Accepted
Date: 2026-09-01

## Context

Phase 002C rejected direct whole-package adoption and found only two balanced cases at repeat depth
one. The formal Skill is still a scaffold. Performance of sanitized instructions cannot resolve
license, contamination, second-state, second-orchestrator or scope blockers.

## Decision

Do not copy, install, execute or integrate upstream candidate content in Phase 002D. Complete the
new cohort, deterministic hard Gates, native read-only audits, automated decisions, Decision Audit
and stable replay first. The system may reject every option or abstain. Phase 003 is not part of
this task even if a later audited route permits it.

## Consequences

Any positive component outcome is limited to `SPECIFICATION_ONLY` and must be implemented later as
clean-room project-native work. The formal Skill remains `0.1.0-foundation` and `SCAFFOLD_ONLY`.
