## 按原题实际强度的科学结论

### 问题 1

九条电流曲线均交付明确结点和分段多项式系数。PCHIP 每段是初等多项式，可以合理地满足“用初等函数表示”这一通常解释；不是低参数单一全局公式，报告已披露。不能没有题面依据就强制增加“必须一个全局初等式”的要求。

MRE 使用已放电时间作为分母，量纲为 1；表中百分数乘了 100，时间单位为 min。231 个电压格点为 9.000–10.150 V，步长 0.005 V。模型反解与原始样本的最后向下分段线性反解相比，选中候选各电流 MRE 为：
20–100 A 依次 0.059976%、0.097080%、0.111471%、0.151977%、0.142186%、0.038885%、0.036627%、0.031723%、0.032103%。

我自己的系数反解复算与已存 MRE 最大差低于 3.1e-16；五个要求的剩余时间为 591.678153、429.791455、326.197390、277.936587、254.685484 min，与原输出一致。导出的系数文件与 Run 完整系数相同。拟合 MRE 与这些条件模型值可获局部支持，但拟合误差不能直接视为新电池的实测预测误差。

附件要求从低电压端取 231 点且相邻电压间距不超过 0.005 V，并没有指定唯一的 231 点清单。实现采用公共格点并插值取得“采样时间”，是透明、可复算的操作解释；并非逐个原始电压记录的直接抽取，不能声称唯一逐字解释。原始曲线不严格单调，低压格点也有多个向下穿越，最多观察到 4 个；选择最后向下穿越是额外但已披露的规则。独立 checker 的全区间二分本身不是一般非单调曲线求逆证明；本次实际结果已经通过独立的分段局部求逆一致性核验。这些解释应随 MRE 保留。

## 必须保留的协议科学异议

1. **将未知目标当作必需输入过强。** frozen problem_requirements 为问题 3 的 minimum_data_fields 增加 state3_terminal_elapsed_min，data_sufficiency 据此为 PARTIAL，controller 据此拒绝。这是冻结 case 需求定义导致的机械拒绝。原题要求预测未知剩余时间，没有要求先取得该未知终止时刻。已知未来目标才允许作答不是适当的预测任务完成标准。预测精度应由适当的先前状态回测、迁移假设检验与不确定性支撑；未知目标本身不能证明题目不可完成。本 episode 仍必须遵守冻结 Gate，不能据此补标签、换协议或过 Gate。
2. **实体重叠不能脱离目标解释。** 原题恰是同一电池跨衰减状态预测。若目标是该电池的后续状态，前序状态作为训练参考是合理条件信息；并不自动造成目标泄漏。若目标改为新电池总体泛化，则电池组间分离才是另一要求。通用 compare-check 对 group_overlap 一律拒绝，适合防止独立实体数虚报，但对这里的条件时序任务过于粗。现有群组重叠与行相关性真实存在，必须披露；不能改为 false 绕过机器拒绝。
3. **原始数据审计与参考答案污染应区分。** 本 episode 读取所有工作簿标签后再划分，不能冒充预先未见 Final；但没有打开参考解答的证据。操作性“整个工作簿被物化”限制了本协议可用的 untouched Final，不能让已有历史数据的常规交叉验证失去所有科学信息。未来协议需要在数据审计和标签访问之间定义可实施边界，而本 episode 不得回滚访问记录。
4. **终局元数据需要准确释义。** experiment_plan 和 model_comparison_candidate 中 handoff_generated_at=22:17:30Z 是预先写入的候选停止截止值，晚于 21:25:43Z 固定包，不是实际 handoff 生成时间。robustness_candidate 的 status=VALIDATED 与正式阶段 11 NOT_REACHED 并存，应按候选局部记录理解。requirement_selection 的 ACCEPTED / selection-check PASS 仅是局部输出绑定，不接受科学比较或 Final。原记录保持不变，终局处理必须解释这些局限。

这些是实际科学/语义意见，其中前两项涉及任务目标与验证设计，不可能靠一个单测把科学争议“测成通过”。本审核不修改 Skill、契约、需求、模型、参数或结果，也不允许用审核意见覆盖技术拒绝。
