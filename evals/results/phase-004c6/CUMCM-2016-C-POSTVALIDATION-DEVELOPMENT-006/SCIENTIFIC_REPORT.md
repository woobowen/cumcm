## 时间与指标语义

模型仅使用预测起点以前已观测的历史状态以及目标状态前缀。时间索引使用 `10000 × state + elapsed_min` 表示状态先后顺序，不能解释为真实日历。状态1的三个起点只使用状态0与各自前缀；状态2只使用状态0/1与各自前缀；状态3的预测只使用状态0/1/2和已观测前缀。所有六个用于选择的历史终止标签都早于状态3预测起点。

Q3误差逐样本计算：`abs((predicted_end-origin) - (observed_end-origin)) / (observed_end-origin)`，再等权算术平均。分母是实际 remaining time，单位min；最终比例无量纲、方向MIN、零分母REJECT。样本单位为“电池状态—预测起点”，六样本相关，不能当成六个独立电池。Q1/Q2则为电流—电压点上的elapsed-at-voltage误差，两个量不互相替代。完整定义与样本计数已绑定实验计划和checker。
