# 旧固定输出与新Development：只读算术比较

本次补齐任务书要求的旧输出/新运行区分。标准库脚本读取已公开的冻结结果、历史审计中的派生真值与新Development摘要，
不读取工作簿或答案，不加载模型/checker实现，不拟合或求解，不启动任何注册Run、checker、Final。
本次比较是主Agent的只读算术核验，未声称另有原生独立审核。

第一次只读核对还交叉读取了新Run的固定output，其SHA与公开摘要一致；第二次改为全部从公开文件重放，
2016比较结果逐字段一致。两次调用均exit0；不是两次新科学实验。源码与结果见
[可重放脚本](compare_fixed_outputs.py.txt)、[全部数值及输入哈希](comparison.json)、[发布说明](publication.json)。

## 2016：相同起点结果相同，不能把换指标/样本称为精度提升

| 比较项 | 旧固定CUBIC输出只读计算 | 新CUBIC_LOG_AFFINE实际Run |
|---|---:|---:|
| Q1九组拟合MRE的均值 | 0.0780032385% | 0.0780032385% |
| Q2七组留一电流MRE的均值 | 1.0219758766% | 1.0219758766% |
| Q2 55A条件总时长 | 1162.58811744 min | 1162.58811744 min |
| Q3状态1、9.765V起点的remaining误差 | 4.1000885379% | 4.1000885379% |
| Q3状态2、9.765V起点的remaining误差 | 8.1185989791% | 8.1185989791% |
| 当前条件剩余时间 | 193.441777244 min | 193.441777244 min |

Q3直接用旧固定预测向量的末值，结合旧公开审计中实际总时长/前缀末剩余时长，计算
`abs(predicted_end - observed_end) / observed_remaining`，没有重新拟合。
若错误地除以总elapsed时长，同两点会变为约1.0291044095%和2.1113332994%；分母不同，不能替代remaining误差。
与新Run相同起点的误差差异均小于3.2e-15，来自浮点平移，不构成新模型效果。

旧两个起点的remaining均值为6.1093437585%；新六个起点为5.1965754106%。
新设计增加9.95V、9.85V起点，**样本集合不同，不能据此宣称误差下降或泛化改进**。
旧joint_validation_MRE为0.8105548796%，目标/聚合亦不同，不能与新remaining-MRE直接排名。
Baseline同样保留：旧两起点remaining均值6.9250265392%，新六起点5.9408550113%；相同起点数值一致。

Q1/Q2这里重聚合的是既有各组MRE，不冒称重新独立反解全部曲线。
当前未来终止时间仍未知；相同条件预测值及算术一致性均不提供新的未来准确率证据。
新Development确有自己的实际模型执行回执，数值与旧结果一致体现了复用确定性模型，并非新增科学优越性。

```sh
.venv/bin/python evals/results/phase-004c6/continuation_001/fixed_output_comparison/compare_fixed_outputs.py.txt \
  --repo-root . --output-dir .cache/pr12-rc9/new-fixed-output-comparison
```
