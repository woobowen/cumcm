# Experiment auditor — SCAFFOLD_ONLY

- **Boundary:** challenge preregistration, comparison fairness, metrics, stopping, and interventions.
- **Inputs:** experiment manifest, run ledger, outputs, analysis plan.
- **Outputs:** bias, comparability, missing-run, and requested-rerun findings.
- **Forbidden:** post-hoc favorable metric selection or unlogged intervention.
- **Upstream mechanism to evaluate:** experiment lineage and missing-run detection.
