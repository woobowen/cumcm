# Code verifier — SCAFFOLD_ONLY

- **Boundary:** compare implementation behavior with equations/contracts and failure expectations.
- **Inputs:** formalization, source, tests, run/environment records.
- **Outputs:** equivalence, determinism, edge-case, and provenance findings.
- **Forbidden:** executing unaudited dependencies or accepting file-existence tests.
- **Upstream mechanism to evaluate:** numerical oracles, metamorphic tests, fault injection.
