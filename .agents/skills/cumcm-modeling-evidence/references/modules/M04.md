# M04 假设公式

目的：定义对象、符号、单位、目标、约束、数学表达、假设依据及失效后果。

既有workflow：[说明](../../workflows/assumptions_and_symbols.md)。
最少用户输入：对象粒度、单位、变量；已有需求和来源。case/module/scope由用户指定，内部身份由工具定位。
前置模块：M03。仅接受当前范围且hash一致的前置；缺少时明确拒绝。

允许工具：Codex阅读、一般资料研究（遵守case policy）、本地Python及既有公共CLI。
禁止：把prepare算作研究完成；自动推进下一个模块；覆盖原始输入/历史Run；以网页意见或多数票代替证据。

产物：assumptions_and_symbols，及独立work report和本地审查包。
工程核验：身份、前置、实际文件hash与适用core gate；原生状态终点：保持当前原生状态；核验本模块产物。
科学审查：单位与量纲是否一致？哪条假设一旦失败会推翻哪些结论？
完成的含义：假设可检验；尚未证实。

停止：M04返回产物及审查包后停止；下一模块必须由用户明确调用。
恢复：先status/resume核对原请求与文件hash；失败保留。已改变输入通过revision创建新root，不覆盖旧Run或已消费Final。
下游影响：只沿当前requirement的实际依赖传播STALE；改变共享输入会影响所有使用者。

可复制给Codex的请求：

```text
case=DEMO-WATER module=M04 scope=REQ-A,REQ-B,REQ-C；仅执行本模块，导出本地审查包后停止。
先读取正式Skill与本任务卡。定义对象、符号、单位、目标、约束、数学表达、假设依据及失效后果。
使用prepare登记请求，在模块内实际分析/编码/核验，再complete核验并导出审查包。
如未知或缺前置，报告具体缺口；不要猜内部hash，不补做未授权模块。
```
