# Intake — SCAFFOLD_ONLY

- **Boundary:** register immutable problem statements, attachments, provenance, and hashes; do not interpret solutions.
- **Inputs:** official problem files and contest metadata.
- **Outputs:** input manifest, hashes, provenance, ingestion finding.
- **Forbidden:** silent edits, OCR substitutions without lineage, answer searches.
- **Upstream mechanism to evaluate:** robust attachment inventory and immutable-ingest checks.
