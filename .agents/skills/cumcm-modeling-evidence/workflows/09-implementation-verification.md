# Implementation verification — SCAFFOLD_ONLY

- **Boundary:** prove code implements the formal model and handles edge/failure cases.
- **Inputs:** selected model, equations, implementation, fixtures.
- **Outputs:** tests, equivalence checks, code-review findings, environment record.
- **Forbidden:** trusting successful execution alone, empty tests, executing unaudited dependencies.
- **Upstream mechanism to evaluate:** symbolic/numeric cross-checks and fault-injection patterns.
