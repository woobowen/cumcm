# Baseline — SCAFFOLD_ONLY

- **Boundary:** specify the simplest reproducible comparator and its failure expectations.
- **Inputs:** formalization, audited data, metrics.
- **Outputs:** baseline model card, config, run record, diagnostics.
- **Forbidden:** tuning on held-out data, non-reproducible manual outputs, unfair metrics.
- **Upstream mechanism to evaluate:** baseline templates and minimum reproducibility gates.
