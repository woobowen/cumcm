# Requirement trace — SCAFFOLD_ONLY

- **Boundary:** decompose every explicit/implicit deliverable into testable requirements.
- **Inputs:** selected immutable statement and official rules.
- **Outputs:** requirement IDs, dependencies, acceptance evidence, ambiguity log.
- **Forbidden:** dropping clauses, inventing requirements, resolving ambiguity silently.
- **Upstream mechanism to evaluate:** coverage matrices and prosecutor-style missing-clause checks.
